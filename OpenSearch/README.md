# Bitbucket Repository Activity Reporting System

A high-performance, lightweight, database-free Flask reporting system designed for **Bitbucket Data Center** and **Stiltsoft Awesome Graphs REST API**.

The application provides monthly and ad-hoc activity reporting across Bitbucket projects and repositories, calculating commit counts, pull request counts, contributor activity matrices, interactive timeline charts, and unified search.

---

## 1. Key Architectural Features

- **Hybrid API Pipeline**:
  - **Bitbucket Data Center API (`/rest/api/latest`)**: Discovers projects (`/projects`), project details, and repositories (`/projects/{key}/repos`).
  - **Stiltsoft Awesome Graphs API (`/rest/awesome-graphs-api/latest`)**: Extracts commits and pull requests per repository with high-performance date range filtering (`sinceDate`, `untilDate`).
- **Strict Separation of Concerns (Zero In-Process Scans in Flask)**:
  - **Flask Server**: Serves purely as a presentation dashboard and report-pulling server. It **never** executes heavy scan runner workloads in-process.
  - **Scan Runner**: A standalone execution engine run via CLI (`python app/main.py scan`) or automated as a Jenkins CI/CD pipeline job.
- **Smart "Pull-from-Artifactory If Present" Resolver**:
  - When viewing or requesting a report for a given month:
    1. Checks local cache (`./data/reports/YYYY/MM/latest/report.json`).
    2. If missing locally, checks Artifactory (`bitbucket-reports/YYYY/MM/latest/`). If present (e.g. generated by your Jenkins job or another server), pulls and loads it into local cache immediately without rescanning!
    3. If not found in either, prompts the user to trigger the external Jenkins job or CLI scan.
- **Zero Database (DB-Free Architecture)**:
  - No SQLite or PostgreSQL dependencies or migrations.
  - Active datasets reside in-memory for instant timeline slicing and search.
  - Historical snapshots are archived as standard `report.json`, `report.csv`, and `metadata.json` files on disk and in Artifactory.
- **Enterprise Multi-Stream Logging with Unique Trace IDs**:
  - Every scan run generates a unique `Trace ID` (`trace-<uuid4>`), attached to all log records and HTTP calls across worker threads.
  - Four synchronized log destinations:
    1. `logs/projects.log`: Logs project discovery, repository discovery, and limit enforcement.
    2. `logs/awesome_graphs.log`: Logs every Awesome Graphs HTTP query (URL, date range query params, HTTP status, duration ms, page size).
    3. `logs/console.log`: Consolidated master log capturing all application events.
    4. Terminal stdout stream.
- **Interactive UI Dashboard with Multi-Tab Navigation**:
  - **Top Navigation Bar**: Seamlessly switch between three views:
    1. 📊 **Overview**: Single-month detailed activity report, efficiency metrics, dynamic timeline chart, and expandable repository breakdown with user drill-downs.
    2. 📈 **Trend Analysis**: Analyze multi-period trends at project and repository levels across **Monthly** and **Quarterly** intervals.
    3. ⚖️ **Comparison**: Side-by-side performance variance analysis between any two months or quarters with delta pills and repository breakdown.
  - **Engineering Efficiency & Code Churn**:
    - Displays 8 standardized engineering efficiency checks: `Avg Commits / Repo`, `Avg Commits / Project`, `Avg Commits / User`, `Avg PRs / Repo`, `Avg PRs / Project`, `Avg PRs / User`, `Avg Lines / Commit`, and **`Total Lines Added`**.
    - LOC badge summary pill displaying `+Lines Added`, `-Lines Deleted`, and `Net LOC`.
  - **Month Picker & Presets**: Automatically computes half-open UTC intervals (`start <= event_time < end`) to prevent boundary issues. Presets for Current Month, Previous Month, Last 30 Days, Last 7 Days.
  - **Dynamic Timeline Chart**: Bar chart showing daily commit & PR trends. Clicking any date or range recalculates KPI cards dynamically via `/api/reports/summary`.
  - **Expandable Repository Rows**: Click any repository row to reveal the full contributor breakdown table (User ID, Display Name, Commits, PRs, Lines Added, Lines Deleted).
  - **Trend Analysis Suite**:
    - Interval toggle (**Monthly** vs **Quarterly**).
    - Scope filters: Filter by project (e.g. `PAY`, `CORE`, `AUTH`) and drill down to repository level.
    - Configurable range: Last 3, 6, 12 periods, or All Available.
    - Three visual trend charts: **Activity Trend** (Commits & PRs), **Code Velocity & Volume** (Lines Added (+) and Deleted (-)), and **Efficiency Checks Trend** (Avg Commits/User, Avg PRs/User, Avg Lines/Commit).
    - Comprehensive period-by-period breakdown table.
  - **Comparison Suite**:
    - Compare by **Month vs Month** or **Quarter vs Quarter**.
    - Base Period and Comparison Period selectors with project and repository filtering.
    - 13 side-by-side efficiency cards with delta badges (`▲ +%` / `▼ -%`).
    - Grouped bar comparison chart comparing commits, PRs, lines added, and active contributors.
    - Detailed metric variance table with absolute differences and percentage variance.
    - Repository-level comparison table showing per-repo variance across all metrics.
  - **Unified Search & Commit Graph Suite (Users, Projects, Repositories)**:
    - Instant search across user IDs, project keys/names, and repository slugs/names.
    - **Contributor Profile & Commit Graph**:
      - Click any contributor name or search result to open the user modal.
      - Single Project: Shows daily commit and pull request timeline trends.
      - Multiple Projects: Shows stacked comparative timeline across all contributed projects, plus a detailed repository contribution table.
    - **Project Profile & Multi-Repo Commit Graph**:
      - Click any project key in the repository table or search modal.
      - Displays project KPIs (commits, PRs, repositories count, active contributors).
      - Single Repo: Shows daily commit and PR trends.
      - Multiple Repositories: Stacked multi-color commit graph comparing each repository over time, plus repository breakdown table with share (%) of total.
    - **Repository Profile & Contributor Commit Graph**:
      - Click any repository name in the table or search modal.
      - Displays repository KPIs (commits, PRs, commit authors, active contributors).
      - Interactive commit & PR timeline and stacked multi-contributor comparison graph.
  - **Export Actions**: Direct download of `report.csv` and `report.json`.
  - **Pluggable "Run Now"**: When Jenkins integration is enabled, triggers the remote Jenkins scan job via REST API; otherwise displays clear execution instructions.

## 3. How to Run the Code

### 3.1 Installation

Ensure Python 3.10+ is installed:

```bash
cd Bitbucket/CodePR_Review
pip install -r requirements.txt
```

Set your credentials as environment variables:

```bash
# Bitbucket Data Center credentials
export BITBUCKET_USERNAME="your_username"
export BITBUCKET_PASSWORD="your_password"

# Optional: Artifactory credentials (if enabled in config.yaml)
export ARTIFACTORY_USERNAME="artifactory_user"
export ARTIFACTORY_PASSWORD="artifactory_password"

# Optional: Jenkins credentials (if remote trigger enabled)
export JENKINS_USERNAME="jenkins_user"
export JENKINS_TOKEN="jenkins_api_token"
```

*(On Windows PowerShell, use `$env:BITBUCKET_USERNAME = "your_username"`).*

---

### 3.2 Starting the Flask Dashboard (Web Server)

Start the web dashboard server:

```bash
# Using default host and port from config.yaml
python app/main.py serve

# Or with custom host/port:
python app/main.py serve --host 0.0.0.0 --port 5000
```

Open your browser at **`http://localhost:5000`**.

---

### 3.3 Running the Standalone Scan Runner (CLI)

The scan runner runs independently from Flask. You can execute it on your local machine, a dedicated worker node, or a cron job:

```bash
# Run scan for specific month:
python app/main.py scan --month 2026-09

# Run scan using custom configuration file:
python app/main.py scan --month 2026-09 --config config/my_config.yaml

# Generate realistic mock data for testing UI without Bitbucket credentials:
python app/main.py scan --month 2026-09 --mock
```

---

### 3.4 Running via Jenkins Pipeline (`Jenkinsfile`)

A turnkey `Jenkinsfile` is provided in the repository root.

1. Create a **Pipeline** job in Jenkins pointing to this repository.
2. Configure credentials in Jenkins Credentials Store:
   - `bitbucket-user-creds-id` / `bitbucket-pass-creds-id`
   - `artifactory-user-creds-id` / `artifactory-pass-creds-id`
3. The job can be scheduled (e.g. monthly cron `0 2 1 * *`) or triggered manually with parameters:
   - `MONTH`: `2026-09`
   - `WORKERS`: `5`
   - `MOCK_SCAN`: `false`
4. The pipeline scans Bitbucket DC + Awesome Graphs, archives artifacts, and publishes reports directly to Artifactory.
5. In the Flask UI, simply click **"Pull from Artifactory"** or select the month to load the new report immediately.

---

### 3.5 Running via Docker

Build and run using Docker:

```bash
# Build Docker image
docker build -t bitbucket-activity-report .

# Run the Flask dashboard
docker run -d -p 5000:5000 \
  -e BITBUCKET_USERNAME="user" \
  -e BITBUCKET_PASSWORD="password" \
  bitbucket-activity-report

# Run a one-off CLI scan container
docker run --rm \
  -e BITBUCKET_USERNAME="user" \
  -e BITBUCKET_PASSWORD="password" \
  bitbucket-activity-report python app/main.py scan --month 2026-09
```

---

### 3.6 Running the Test Suite

Run the full automated test suite:

```bash
python -m pytest tests/ -v
```

All 17 unit and integration tests verify:
- Configuration parsing and secure environment variable resolution.
- Bitbucket DC project and repository discovery.
- Awesome Graphs query handling and pagination.
- Trace ID propagation across all 3 log files (`projects.log`, `awesome_graphs.log`, `console.log`).
- Aggregator calculations, user drill-downs, and CSV exports.
- Local FileStore saving and retrieval.
- Monthly and quarterly aggregation, quarter conversion helpers, and project/repo filtering.
- Trend Analysis building and multi-period efficiency metric summaries.
- Comparison suite delta calculations, percentage variance, and repository breakdowns.
- Flask API routes (`/health`, `/api/config`, `/api/reports/latest`, `/api/reports/summary`, `/api/reports/periods`, `/api/reports/trend`, `/api/reports/compare`, `/api/search`).
- Enforcement that Flask prohibits in-process runner execution.

## 5. API Endpoint Summary

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Web Dashboard user interface (Overview, Trend Analysis, and Comparison tabs). |
| `GET` | `/health` | Healthcheck endpoint (`{"status": "healthy"}`). |
| `GET` | `/ready` | Readiness probe endpoint (`{"status": "ready"}`). |
| `GET` | `/api/config` | Exposes safe, non-sensitive configuration settings. |
| `GET` | `/api/reports/latest?month=YYYY-MM` | Resolves report: checks local cache, pulls from Artifactory if missing, returns JSON. |
| `GET` | `/api/reports/summary?month=YYYY-MM&from=...&to=...` | Slices timeline data for dynamic chart range recalculation. |
| `GET` | `/api/reports/repositories?month=YYYY-MM` | Returns repository list with detailed user contributor drill-downs. |
| `GET` | `/api/reports/periods` | Discovers and returns all available months, quarters, projects, and repositories. |
| `GET` | `/api/reports/trend?interval=month\|quarter&project=...&repo=...` | Computes historical multi-period trend metrics at project and repository levels. |
| `GET` | `/api/reports/compare?type=month\|quarter&period1=...&period2=...` | Side-by-side comparison of two periods with 13 metric deltas and repo breakdown. |
| `GET` | `/api/reports/export?month=YYYY-MM&format=csv` | Downloads report as a CSV file. |
| `GET` | `/api/reports/export?month=YYYY-MM&format=json` | Downloads report as a JSON file. |
| `GET` | `/api/search?q=...&month=YYYY-MM` | In-memory search over projects, repositories, and user IDs. |
| `POST` | `/api/reports/jobs/run` | Triggers external Jenkins job (if enabled) or returns external CLI run instructions. |
